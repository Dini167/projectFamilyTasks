# projectFamilyTasks

## על המערכת

מערכת לניהול משימות הבית וחלוקת תפקידים במשפחה ברוכת ילדים. ההורים מגדירים משימות (עם גיל מינימלי, זמן משוער,
תדירות וערך נקודות), פותחים סבב בחירה וקובעים כמה משימות כל ילד רשאי לבחור באותו סבב. הילדים נרשמים, ממתינים
לאישור הורה, ורואים בסבב רק משימות שמתאימות לגילם. הילד תופס משימות לפי הכלל "הראשון שמגיע מקבל", מסמן "ביצעתי"
וצובר נקודות. החלפת משימה בין ילדים עוברת אישור דו-שלבי: האח מאשר, ואז הורה מאשר, ורק אז השיבוץ מתעדכן. בנוסף יש
צ'אט משפחתי אחד פתוח לכל החברים. השרת בנוי ב-.NET 8 (Web API) בארבע שכבות: Domain, Application, Infrastructure ו-API,
עם PostgreSQL והזדהות באמצעות JWT.

## המשאב המוגבל והתחרות עליו

המשאב המוגבל הוא **משימה בסבב** (`Assignment`): משימה אחת יכולה להיות שייכת לילד אחד בלבד. כשכמה ילדים לוחצים על אותה
משימה פנויה באותו רגע, התחרות מתרחשת בשמירה לבסיס הנתונים. לכל שיבוץ יש שדה גרסה (`Version`, מסוג `Guid`) שמוגדר
כ-concurrency token של EF Core, והגרסה מתחלפת בכל שמירה. הילד הראשון שומר בהצלחה והמשימה נרשמת על שמו. אצל הילד
השני העדכון מתייחס לגרסה ישנה, ולכן EF Core זורק `DbUpdateConcurrencyException`. ה-`UnitOfWork` תופס אותו ומתרגם
לשגיאת **409 Conflict** עם הודעה בעברית (המשימה כבר נתפסה), והאתר מציג אותה לילד ומרענן את רשימת המשימות הפנויות.
כך אין צורך בנעילות, ושני ילדים לעולם לא מקבלים את אותה משימה. בדיקת היחידה `AssignmentConcurrencyTests` מדמה את
המצב עם שני `DbContext` ומוכיחה שהשני נכשל.

## הוראות הרצה

**דרישות:** .NET 8 SDK, ו-Docker עבור PostgreSQL 16.

1. הרצת בסיס הנתונים (קונטיינר בשם `pg`, בפורט 5432):

   ```
   docker run --name pg -e POSTGRES_PASSWORD=<סיסמה> -p 5432:5432 -d postgres:16
   ```

2. שמירת הסודות ב-User Secrets (לא נשמרים ב-git). המפתח צריך להיות באורך 32 תווים לפחות:

   ```
   dotnet user-secrets set "ConnectionStrings:Default" "Host=localhost;Port=5432;Database=familytasks;Username=postgres;Password=<סיסמה>" --project projectFamilyTasks.Api
   dotnet user-secrets set "JwtSettings:Key" "<מפתח-אקראי-באורך-32-תווים-לפחות>" --project projectFamilyTasks.Api
   ```

3. הפעלת השרת:

   ```
   dotnet run --project projectFamilyTasks.Api --launch-profile http
   ```

   בעליית השרת ה-migrations מוחלים והנתונים ההתחלתיים נוצרים אוטומטית. Swagger נפתח בכתובת
   `http://localhost:5231/swagger`.

4. הרצת הבדיקות: `dotnet test projectFamilyTasks.slnx`
